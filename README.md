# Nexus English App (CEFR A1 — B2)

Офлайн-ориентированное приложение для изучения английского языка, созданное по лекалам **Nexus Hebrew App** на базе Flutter, чистой модульной архитектуры (Clean Architecture / DDD), локальной реактивной базы данных **Drift (SQLite)**, интервальных повторений **FSRS** и гибридного аудио-движка (TTS + нативные аудиофайлы).

---

## 🎯 Ключевые возможности и модули

### 1. Главная панель (English Dashboard)
* Приветствие по времени суток (*Good morning / Good evening*).
* **Слово дня (Word of the Day):** карточка с бейджем уровня CEFR, транскрипцией IPA, переводом, озвучкой и возможностью добавить в карточки в 1 клик.
* **Daily Workout & Streak:** трекер ежедневных серий и целей.
* Сетка быстрого доступа ко всем разделам приложения.

### 2. Диалоги (Interactive Branching Dialogues)
* Разветвленные сценарии общения по уровням CEFR:
  * **A1:** Заказ кофе в кофейне в Лондоне.
  * **B1:** Техническое собеседование на позицию инженера.
* Озвучка реплик через TTS (американский или британский акцент).
* Мгновенное добавление понравившихся фраз в карточки FSRS.

### 3. FSRS Карточки (Spaced Repetition System)
* Алгоритм интервальных повторений памяти FSRS.
* Переворот карточки (Лицевая сторона — English, Оборот — Русский, IPA, примеры).
* **Режим ввода с клавиатуры:** проверка спеллинга слов с мгновенной валидацией.
* Оценки: *Снова (1)*, *Трудно (2)*, *Хорошо (3)*, *Легко (4)*.

### 4. Грамматика & Атлас глаголов (Grammar & Verbs)
* **Атлас неправильных глаголов (V1 → V2 → V3):** интерактивная таблица с поиском, озвучкой трех форм и контекстными примерами.
* **Тренажер-квиз по глаголам:** быстрая проверка знания форм V2 и V3.
* **Темы CEFR (A1-B2):** структурированные уроки с формулами, маркерами времени и встроенными интерактивными тестами.

### 5. Аудирование & Диктанты (Listening Lab)
* **Слуховые диктанты:** слушай и пиши на слух с оценкой точности совпадения.
* **Пазлы предложений:** сборка предложений из слов в правильном порядке.
* **Минимальные пары (Minimal Pairs):** тренировка различения близких звуков (*sheep/ship*, *bad/bed*, *think/sink*) — ключевая особенность английской фонетики.
* Переключение скорости аудио (0.75x / 1.0x).

### 6. Умный словарь CEFR (Smart Dictionary)
* Поиск по словам на английском и русском языках.
* Фильтрация по уровням CEFR (A1, A2, B1, B2).
* Транскрипция IPA, аудио-произношение, части речи и примеры.
* Кнопка **«Добавить своё слово»** для пополнения словаря и колоды FSRS.

### 7. Фразовые глаголы & Идиомы (Phrasal Verbs)
* Золотой фонд фразовых глаголов (*give up*, *figure out*, *run into*) и идиом (*bite the bullet*, *break a leg*).
* Пометки формальности (*Neutral, Informal, Business, Idiom*).
* Примеры с озвучкой и перевод.

### 8. Адаптированное чтение (Graded Reader Stories)
* Рассказы по уровням от A1 до B2.
* Чтение с синхронным переводом по абзацам.
* Озвучка отдельных предложений и всего рассказа.
* Тест на понимание прочитанного в конце каждой истории.

### 9. Фонетика & 44 Звука (Phonics & IPA)
* Интерактивная звуковая панель (Sound Board) 44 звуков английского языка (краткие/долгие гласные, дифтонги, звонкие и глухие согласные).
* Аудио-примеры каждого звука по клику.
* **Атлас немых букв (Silent Letters):** правила и примеры для букв K, B, W, L, T.

### 10. Прогресс & Настройки
* GitHub-style Heatmap активности.
* Графики освоения уровней A1 → B2.
* Переключение акцента TTS (**en-US** / **en-GB**).
* Регулировка скорости речи и переключение темы (Light / Dark / System Material 3).

## 🚀 Запуск проекта

```bash
# Перейдите в папку проекта
cd nexus_english_app

# (Или через симлинк в Downloads)
# cd "/Users/badmuchi/Downloads/Nexus English App"

# Установка зависимостей
flutter pub get

# Генерация кода базы данных Drift
dart run build_runner build --delete-conflicting-outputs

# Запуск приложения на macOS / Chrome / iOS / Android
flutter run
```
